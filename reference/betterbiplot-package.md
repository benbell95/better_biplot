# betterbiplot: Better Looking Biplots in Base R

Creates customisable biplots for Principal Component Analysis (PCA)
using only base R graphics. Supports 'prcomp()', 'princomp()',
'vegan::rda()', 'survey::svyprcomp()', 'FactoMineR::PCA()',
'ade4::dudi.pca()', and 'psych::principal()' objects as well as custom
score and loading matrices, with support for grouping by colour, symbol,
and size, covariance and Hotelling-t ellipses, convex hulls, centroids,
spider lines, circles of equilibrium contribution, label rotation, and
selective legends.
